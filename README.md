# QuickTools

A minimalist, browser-only utility website with **85 working tools** and no backend dependency.

## Included categories

- Calculators
- Finance
- Measurements and unit conversions
- Engineering and electrical tools
- Date & time
- Text utilities
- Developer utilities
- Random and content generators

Highlights include percentage/ratio/average calculators, EMI and interest calculators, GST/VAT and margin tools, 14 families of measurement converters, fuel economy conversion, battery runtime and energy tools, Ohm’s law, voltage divider and resistor network calculators, gear ratio and wheel speed tools, date arithmetic, JSON/Base64/URL/HTML utilities, number-base and color conversion, SHA-256, UUID/JWT tools, password/PIN/random generators, and more.

Everything runs locally in the browser. No sign-up, database, API key, or server is required.

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Hosting

Works on GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static web host.

## Ad integration

`index.html` contains a hidden `.ad-slot` placeholder. Keep it hidden until an ad provider such as Google AdSense is configured. Avoid placing ads inside tool controls or where they could cause accidental clicks.
